How to use a cheat table

  1. Install Cheat Engine (decline any bundled offers in the installer).
  2. Back up your save files.
  3. Start the game and load into your save.
  4. Open Cheat Engine, click the computer icon (top left) and pick the game's .exe from the process list.
  5. Use File → Open to load the .CT file you downloaded.
  6. Tick the box next to a group to turn it on, then double-click a value to change it. Keep menus closed while editing.
