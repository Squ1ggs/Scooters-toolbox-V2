Which phosphenes each boss can drop. Percentages are on the Boss drop rates tab. Use the UVH / Mayhem level slider there to see how rates scale.

How to read the percentages: Each ≈% is an estimate for that boss kill, from the game’s dedicated-drop tables. Default rates are at UVH 0. Use the UVH / Mayhem level slider above to apply the game formula (UVH × slot scalar) + base chance — campaign uses UVH_Scalar; raids use Mayhem_Scalar on their own tables. When several items share the same loot tier, we assume an equal split. Some rows show the loot tier only when a rate could not be calculated. Party size does not change these per-kill boss slot rates in the export — co-op means more kills, not a higher % per kill. Vault cards, challenges, and event drops for non-boss phosphenes are on the first tab — they don’t have boss % here.
