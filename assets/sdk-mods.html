Characters and cars

Borderlands 4 characters are already in the list. These packs add the others. Install the tool once, then add the packs you want.

Characters

Adds one character to Appearance. You still play as yourself.

  • Preview the look beside you, then apply it
  • Restore puts your own character back

Cars

Adds one car to the vehicle list. Driving stays the vehicle you are using.

  • Preview it, summon it, or put it on your current vehicle
  • Restore puts the original vehicle back

Install the tool once

Use the desktop app, or the two standalone mods. You only need one of those.

Desktop app

Characters are on Appearance. Cars are on Vehicle, under Car appearance. Setup can install the game mod files.

Standalone mods

Character Swapper for characters. Vehicle Swapper for cars. Put the .sdkmod in the game's sdk_mods folder and enable it.

Mod downloads BL4 Python SDK

Install

  1. Close Borderlands 4. Use the folder that contains OakGame and sdk_mods.
  2. In the desktop app, open Setup and choose Install downloaded Appearance pack….
  3. Or extract the zip into that Borderlands 4 folder, so it is not left only in sdk_mods or only in Paks.
  4. Load into a map. Characters show up in Appearance. Cars show up after you refresh the car list.

Other players will not see the character or the car. It only shows on your game. To remove one, close the game, delete its folder in sdk_mods/appearance_packs/, and delete the .pak, .utoc, and .ucas files named in its readme from OakGame/Content/Paks.

Back up your save before you install a pack.
